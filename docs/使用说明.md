# My Podcast · 安卓 App 使用说明

安装包：`dist/MyPodcast-v1.3.apk`（约 49 KB，自带播放器 + 全屏播放页 + 录音转文字 + 微信直接导入；桌面图标名 My Podcast）

---

## 一、装到手机

1. 电脑上把这个 apk 发到微信「文件传输助手」
2. 手机上点开文件 → 选「用其他应用打开 / 安装」
3. 小米：会提示「禁止安装未知来源应用」→ 允许本次安装；华为/OPPO 同理
4. 打开 App → 第一次点录音会弹「允许使用麦克风」→ 点允许

> 装过一次再覆盖安装不用卸载，数据保留（v1.2 → v1.3 直接覆盖）。自己重新打包的 apk 签名不同，覆盖安装会失败，需先卸载。

## 二、功能

### 1. 媒体库（听播客）
- **＋ 导入**：选 mp3（可多选），文件名形如 `2026-11-13_标题.mp3` 会自动拆出日期和标题
- 点条目开始播；底部播放条：
  - 点标题或右边的 **⌃** → 打开**全屏播放页**（见下）
  - **🔁 按钮切换播放模式**：顺序播放 → 单曲循环 → 随机播放（点一下换一种，顶部会提示，选择自动记住）
  - **1.0× 按钮**：0.75×～2× 循环切换
- **进度自动记住**：听到一半退出，下次点开接着听
- 锁屏 / 通知栏可以控制播放（系统媒体控制）
- 右上角搜索框按标题或日期筛
- 🗑 删除（只删手机上这份，电脑上的 mp3 不受影响）

### 2. 播放页（v1.3 新增）
从底部播放条点标题或 **⌃** 滑上来，整屏播放：

- 粉色唱片转盘 + 漂浮音符（播放时转，暂停停）
- 标题 / 进度条可拖动 / 当前时间与总时长
- 控制键：模式（🔁🔂🔀）、上一条、↺15、播放/暂停、15↻、下一条、倍速
- **✨ 生成字幕**：把这一条音频传到服务器转写，文字出现在下方字幕区
  - 右下角 **📋 复制** 一键复制全部字幕
  - 按钮会显示「转写中…」，3 分钟音频约 1.5 分钟
  - 服务器返回分段时，字幕按句显示，**点哪句就从那句开始播**；没分段时按句子切开，同样可复制
- 返回键 / 点左上角 ⌄ 收起，继续听，不影响播放

### 3. 录音（练口语复述）
- 点红圆钮开始录，方块停止
- 停止后自动存进媒体库，并在下方「最近录音」出现
- 点 **转成文字** → 上传到你自己部署的转写服务器（见第三节），文字出现在文本框，可复制

### 4. 从微信直接导入（v1.2 起）
微信里收到的音频**不用先「保存到手机」**，直接在微信里：

1. 长按那个 mp3 文件 → **用其他应用打开**
2. 弹出的应用列表里选 **My Podcast**
3. App 自动打开，音频直接进媒体库，提示「已从微信导入 1 个」

手机文件管理器里点 mp3 → 用其他应用打开 → My Podcast 也一样。

> 微信的聊天记录/缓存目录不开放给其它 App，系统选择器里翻不到，所以走「用其他应用打开」这条安卓标准通道；App 里媒体库顶部有这条提示。

## 三、转写服务（需自己部署）

转写用的是 faster-whisper，跑在你自己的服务器上。部署步骤见 [`server/部署说明.md`](../server/部署说明.md)。

部署完之后在 App「设置」页填：

| 项 | 填什么 |
|----|--------|
| 服务器地址 | 你的地址，例如 `https://你的域名/stt` 或 `http://1.2.3.4:8787` |
| 口令 | 部署时设置的 `API_TOKEN`（没设就留空） |

点「测试连接」应显示「连接成功 · 模型 small.en」。

- **HTTP / HTTPS 自动回退**：如果填的地址连不上，App 会自动试同一台机器的另一套入口（http ↔ https 互换），成功后提示并写回设置。
- **站点强制 HTTPS 时注意**：nginx 若把 80 端口的所有请求 301 到 https，浏览器跟随 301 会把 POST 改成 GET，上传会失败（405）。请直接用 HTTPS 地址；或按部署说明「八」给转写路径加一个不跳转的 `location`。
- **速度参考**（2 核 1.8G 小机器）：20 秒音频约 10 秒出字；3 分钟录音约 1.5 分钟。超过 5 分钟会超时，分开录。
- 带时间轴的逐句字幕需要部署 `server/transcribe_server.py` 最新代码（返回 `segments`）；老代码也能用，只是按句子切分、不能点句跳转。

## 四、注意

- 音频只存在手机 App 自己的存储里；**卸载 App 或清除应用数据 = 音频全没**，重要录音先导出去
- 录音是 .m4a（AAC），服务器直接能解
- 转写要联网；没网时录音照样能录能存，等有网再点转文字
- 中文录音：服务器要换非 `.en` 模型，设置页把「默认语言」改成中文再转

## 五、源码结构

```
my-podcast\
  android\               ← App 工程（WebView 外壳 + 原生录音桥）
    assets\index.html    ← 全部界面逻辑
    src\com\yili\podcast\MainActivity.java
    build.sh             ← 一键重新打包（不依赖 Gradle）
  server\                ← 服务器端 faster-whisper 服务
    transcribe_server.py
    部署说明.md
  web\index.html         ← 网页版（浏览器直接打开）
  docs\                  ← 说明文档
  dist\                  ← 打包好的 apk
```

重新打包：

```bash
cd android
bash build.sh
```

需要 JDK 17 + Android SDK（platform android-34、build-tools 34.0.0），路径在 `build.sh` 顶部改。

> v1.3 新增：底部播放条「模式」三态切换（顺序/单曲/随机，自动记忆）；全屏播放页（唱片动画、字幕区、生成字幕、复制、点句跳转、返回键关闭）；转写服务端返回逐句 `segments`。
>
> v1.2 新增：Manifest 注册了 `VIEW / SEND` 的 `audio/*` 过滤器；外部音频先拷到 App 私有目录 `files/imports/`，再通过 WebView `shouldInterceptRequest` 的虚拟地址 `https://local.podcast/imports/<文件名>` 交给页面存进 IndexedDB，导入完即删临时文件（微信里那份原文件不动）。
